# Al-Hatab-Foods---Sales-Retail-Analytics-Dashboard
This project focuses on building an end-to-end retail sales analytics solution for Al Hatab Foods to transform raw transactional data into actionable business insights
Key Features & Capabilities
Centralized Key Metrics: Tracks core KPIs including total revenue, average sales, total product items, and overall customer satisfaction ratings.   SQL-Powered Data Processing: Applied optimized SQL queries to query, clean, aggregate, and structure raw database records before importing them into the Power BI data model.   Outlet Performance Tracking: Evaluates revenue across different store sizes (Medium, Small, High), outlet types (Supermarkets vs. Grocery Stores), and geographical location tiers.   Product & Category Insights: Visualizes inventory assortment, product categories, and consumer preferences such as fat content breakdown.   Historical Growth Analysis: Monitors sales establishment timelines across years to measure store growth trends over time.   Interactive Filtering & Slicing: Integrated dynamic slicers (Outlet Size, Location Tier, Item Type, Fat Content) enabling business stakeholders to perform deep-dive analysis effortlessly.   Tech Stack & Tools:Database & Querying: SQL / PostgreSQL (Data Cleaning, Transformation, Aggregation)Visualization Tool: Power BIAnalytics Focus: Retail Sales Performance, KPI Tracking, Customer Behavior Analysis
